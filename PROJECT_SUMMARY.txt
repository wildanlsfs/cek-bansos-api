verification on https://cekbansos.kemensos.go.id/ with AI-powered 
CAPTCHA solving.

KEY INNOVATION: Dual AI provider support - users can choose between:
  • Local Ollama (free, private, 4GB RAM)
  • 9router Cloud (paid, fast, no setup)

DEPLOYMENT OPTIONS
═══════════════════════════════════════════════════════════════════════

Option 1: 9router Cloud (2 minutes)
────────────────────────────────────
  Setup:     2 minutes
  Cost:      ~$0.001-0.01/request
  Speed:     ~12 seconds per CAPTCHA
  RAM:       None required
  Privacy:   Cloud-based
  
  Command:   docker compose up -d api

Option 2: Local Ollama (15 minutes)
────────────────────────────────────
  Setup:     15 minutes
  Cost:      Free
  Speed:     ~47 seconds per CAPTCHA
  RAM:       4GB+ required
  Privacy:   100% local
  
  Command:   docker compose --profile ollama up -d

API ENDPOINT
